# ⏱️ Blitz Chess Clock

A lightweight, responsive digital chess clock designed for over-the-board play. Built entirely from scratch using HTML, CSS, and vanilla JavaScript. 

This project was built to practice core JavaScript concepts including state management, asynchronous logic (`setInterval`), DOM manipulation, and boolean flags.

## ✨ Features

* **Dual Timers:** Tracks precise time for White and Black independently.
* **Fischer Increment:** Automatically adds a 3-second increment to a player's clock upon completing a move.
* **State Management (Pause/Resume):** Includes a robust pause feature that safely halts the clock and prevents accidental inputs during board disputes.
* **Visual Feedback:** Instantly updates the UI with a green highlight to indicate the active player.
* **Zero Dependencies:** Pure vanilla JavaScript with no external libraries or frameworks.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure and layout.
* **CSS3:** Flexbox styling and interactive visual states.
* **JavaScript (ES6):** Game logic, event listeners, and interval handling.

## 🚀 How to Run Locally

Because this project uses vanilla web technologies, you don't need a server to run it.

1. Clone this repository to your local machine:
   `git clone https://github.com/YOUR-USERNAME/ChessClock.git`
2. Navigate to the project folder.
3. Double-click the `clock.html` (or `index.html`) file to open it in any modern web browser.
4. Set it next to a chessboard and start playing!
